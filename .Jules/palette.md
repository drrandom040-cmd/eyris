## 2026-05-05 - Semantic Content Merging & Accessible Emojis inside Cards
**Learning:** Screen readers pronouncing character-based or emoji contact indicators (e.g., '📷' as "camera" or 'f' as "letter f") interrupts context. Utilizing `clearAndSetSemantics` allows overriding character/emoji descriptions with localized service names (e.g., "Instagram", "Facebook"). Additionally, merging category and rating row details using `mergeDescendants = true` with a custom localized summary prevents screen readers from making fragmented, disjointed announcements of rating numbers/stars.
**Action:** When displaying emoji-based actions or social handle icons, clear their default screen reader semantics and set a descriptive localized `contentDescription`. Merge dynamic layouts (like Category + Rating) into single semantic parent elements to offer a cohesive context summary.
