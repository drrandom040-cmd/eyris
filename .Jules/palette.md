## 2026-07-13 - Optimizing Search Input Flow
**Learning:** Optimizing multi-field search forms with `ImeAction.Next` for intermediate fields and `ImeAction.Search` for the final field, combined with trailing clear buttons, significantly improves the "flow" and speed of user input. Using a logic loop or helper composables to implement these repetitive fields keeps the code concise and helps stay within strict line-count constraints (like the 50-line limit) while providing a robust UX.
**Action:** Always implement standard keyboard actions (Next/Search) and provide one-tap clear functionality for multi-field search screens. Favor iterative or modular implementation patterns to keep UX-heavy UI code clean and review-friendly.
