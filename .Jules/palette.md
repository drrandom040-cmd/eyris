## 2024-05-23 - [Search Input UX Pattern]
**Learning:** For search-intensive input fields in this design system, combining `ImeAction.Next`/`ImeAction.Search` with trailing 'clear' buttons significantly improves interaction speed and keyboard accessibility.
**Action:** Always include a 'clear' button with `contentDescription` and appropriate `ImeAction` for input fields where rapid re-entry or mobile search is a primary user goal.
