## 2025-05-15 - Enhanced Search UX Pattern
**Learning:** For apps with multi-field search interfaces, users expect smooth keyboard transitions and a quick way to reset individual criteria. Standardizing on `ImeAction.Next`/`ImeAction.Search` and trailing clear buttons significantly reduces friction.
**Action:** Apply the `ImeAction` and clear button pattern to all search-intensive `OutlinedTextField` components in future UI enhancements.
