## 2023-11-20 - Jetpack Compose Semantics and Keyboard Flow
**Learning:** In Jetpack Compose, using `Modifier.semantics(mergeDescendants = true)` while setting a custom `contentDescription` on a parent layout completely hides all of the children's semantic details. Therefore, the parent's custom description must explicitly map and output the vital dynamic details from its children (like category, rating, and review count). Also, utilizing `clearAndSetSemantics` on emojis and letter-based indicators prevents screen readers from pronouncing raw characters (e.g. pronouncing 'f' instead of 'Facebook', or '📷' instead of 'Instagram').
**Action:** When designing cards containing visual/emoji indicators and dynamic data rows, explicitly merge the layouts with descriptive parent labels containing the combined data, and apply `clearAndSetSemantics` to replace visual icons/emojis with localized, screen-reader-friendly string resources. Add explicit keyboard options/actions to standard text input flows for seamless form completion.
