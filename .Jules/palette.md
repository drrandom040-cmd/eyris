## 2025-07-29 - Accessible Emojis and Rating Row Semantics
**Learning:** Raw emojis (e.g., '📷', 'f', '🎵', '💬', '📞') inside business cards are extremely confusing for screen readers, as they either pronounce the raw character name incorrectly or lack structural context entirely. Similarly, setting a merged semantics on a rating row hides children's individual text, which can lead to data loss unless the parent description explicitly formats a translatable and complete text representation.
**Action:** Always use `Modifier.clearAndSetSemantics { contentDescription = ... }` with localized, structured strings to override emoji reading, and provide a clear, formatted summary of ratings and counts (e.g., using `R.string.business_rating_summary` with placeholders) to ensure a descriptive and translatable experience.
