## 2026-06-22 - [Optimized Search Keyboard Flow]
**Learning:** Optimizing keyboard flow using `ImeAction.Next` and `ImeAction.Search` along with trailing clear buttons significantly improves search-intensive UI by reducing required taps and managing focus transitions more naturally.
**Action:** Apply `ImeAction.Next` to primary criteria fields and `ImeAction.Search` to the final field to automatically initiate search and hide the keyboard.
